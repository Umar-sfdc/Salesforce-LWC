# JavaScript Foundation

 This section covers the **fundamentals required to get started with Salesforce Lightning Web Components (LWC)**.

 You’ll build a strong foundation in **modern JavaScript (ES6)**, understand the fundamentals of **Web Components**, and get an overview of **Salesforce LWC architecture and project setup**. You’ll also learn the basic Salesforce CLI commands used to **deploy, retrieve, and update components**.
